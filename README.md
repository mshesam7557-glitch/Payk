# پیک — پیام‌رسان وب

پیام‌رسان با پیام متنی و ویس، تماس صوتی و تصویری و اشتراک صفحه (در گفتگوی خصوصی)، گروه، واکنش، پاسخ، ویرایش و حذف پیام،
تم‌های قابل تغییر و بازیابی رمز با «کد بازیابی». روی کامپیوتر و موبایل (داخل مرورگر) کار می‌کند.
عکس، ویدیو و ارسال فایل وجود ندارد (فقط عکس پروفایل).

## اجرا
نیازمند Node.js نسخه‌ی ۲۲.۱۳ یا بالاتر.

    npm install
    npm start          # http://localhost:3000

متغیرهای محیطی (اختیاری):
- `PORT` — پورت (پیش‌فرض ۳۰۰۰)
- `DATA_DIR` — مسیر ذخیره‌ی دیتابیس و فایل‌ها (پیش‌فرض `./data`)؛ روی میزبان‌هایی مثل Render حتماً روی یک دیسک پایدار بگذارید
- `TRUST_PROXY` — تعداد پروکسی‌های جلوی برنامه (پیش‌فرض ۱)

## استقرار روی Render
Build Command: `npm install` | Start Command: `npm start` | یک Disk وصل کنید و `DATA_DIR` را روی مسیر آن بگذارید.

## بازیابی رمز
هنگام ثبت‌نام یک کد بازیابی (مثل `K7QM-2XPA-9TRD-4WHF`) نمایش داده می‌شود. در صفحه‌ی «فراموشی رمز» با نام کاربری و این کد
رمز جدید تنظیم می‌شود و یک کد تازه صادر می‌شود. از بخش تنظیمات ← امنیت هم می‌شود کد جدید ساخت.
(چون ایمیل یا شماره‌ای گرفته نمی‌شود، کد گم‌شده راه بازگشتی ندارد.)

## امنیت
رمزها با scrypt هش می‌شوند، نشست‌ها با کوکی HttpOnly، محدودیت تعداد تلاش، CSP، فایل‌ها فقط برای کاربران واردشده،
فایل‌های غیرمدیا همیشه به‌صورت دانلود سرو می‌شوند.

## تماس صوتی و تصویری
از WebRTC استفاده می‌کند؛ صدا و تصویر مستقیم بین دو کاربر می‌رود و از سرور رد نمی‌شود. سرور فقط پیام‌های هماهنگی را رد و بدل می‌کند.
- تماس فقط در گفتگوی خصوصی (دو نفره) است، نه گروه.
- مرورگر فقط روی HTTPS (یا localhost) اجازه‌ی میکروفون و دوربین می‌دهد؛ روی Render این خودکار است.
- اشتراک صفحه روی کامپیوتر کار می‌کند؛ مرورگرهای موبایل معمولاً پشتیبانی نمی‌کنند و دکمه‌اش نمایش داده نمی‌شود.
- **سرور TURN:** بدون آن، تماس فقط وقتی برقرار می‌شود که شبکه‌ی دو طرف اجازه‌ی اتصال مستقیم بدهد. روی بعضی شبکه‌ها
  (اینترنت موبایل، شبکه‌های سازمانی، فیلترینگ) ممکن است تماس وصل نشود. برای رفع، یک سرویس TURN بگیرید و این متغیرها را تنظیم کنید:
  `TURN_URLS` (مثلاً `turn:turn.example.com:3478,turns:turn.example.com:5349`)، `TURN_USERNAME` و `TURN_CREDENTIAL`.
- `STUN_URLS` (اختیاری): فهرست سرورهای STUN جداشده با کاما؛ پیش‌فرض سرورهای STUN گوگل است.
